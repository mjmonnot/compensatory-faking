# database/

The Stanek and Ones (2023) Personality Traits and Cognitive Abilities Relations Database is
**not redistributed** here (CC BY-NC-ND 3.0 US). Download it from the Data Repository for the
University of Minnesota, https://doi.org/10.13020/7YS8-ET75, and place

    Stanek and Ones - Personality Traits and Cognitive Abilities Relations Database 2023-05-16.xlsx

in this folder, then run `python code/00_load_database.py`. Everything in this folder except
this file is git-ignored.

Citation: Stanek, K. C., & Ones, D. S. (2023). *Personality traits and cognitive abilities
relations database* [Data set]. Data Repository for the University of Minnesota.
https://doi.org/10.13020/7YS8-ET75
